# Employee Equipment Request & Approval Hub

Portfolio project demonstrating a Microsoft 365 equipment-request workflow built around SharePoint Online, Power Apps and Power Automate, with role-based approvals, QA artifacts and a locally validated workflow prototype.

The repository contains the cloud build pack, Power Fx formulas, SharePoint schemas, Power Automate flow specifications, sample data, manual/UAT testing assets and a runnable local prototype.

> Cloud deployment status: tenant validation pending. The local workflow logic and project consistency checks are validated, but SharePoint/Power Apps/Power Automate deployment must still be executed in a real Microsoft 365 tenant before the project is marked CV-eligible.
