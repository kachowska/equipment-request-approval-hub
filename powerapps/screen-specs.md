# Screen specifications

## Visual direction

Use a simple enterprise layout:
- white background
- one primary accent
- 8px spacing grid
- status chips with text labels, not color alone
- form labels always visible
- confirmation messages after save/submit
- responsive containers rather than fixed pixel positioning

## Employee experience

`Home -> New Request -> Save Draft -> Submit -> My Requests -> Details`

Validation:
- title required
- department required
- device type required
- reason minimum 10 characters
- urgency required
- manager must be mapped in `App Roles`

## Manager experience

`Home -> Manager Queue -> Request Details`

The queue is for visibility and review. The authoritative approve/reject action is the Microsoft Approval generated by Power Automate.

## IT experience

`Home -> IT Queue -> Request Details -> In Progress -> Completed`

IT actions must only be visible when `varCurrentRole = "IT"`.
