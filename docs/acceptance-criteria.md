# Acceptance criteria

AC-01 Employee can create a valid draft request.  
AC-02 Missing required fields block save/submit.  
AC-03 Employee only sees own requests in the employee gallery.  
AC-04 Employee can submit a saved draft.  
AC-05 Submitted request becomes `Pending Approval`.  
AC-06 Manager receives an approval request.  
AC-07 Approve changes the request to `Approved`.  
AC-08 Reject changes the request to `Rejected`.  
AC-09 Rejection comment is stored and visible.  
AC-10 Approved requests appear in IT queue.  
AC-11 Rejected requests never appear in IT queue.  
AC-12 IT can set fulfillment to `In Progress`.  
AC-13 IT can set fulfillment to `Completed`.  
AC-14 Completion stores IT identity and timestamp.  
AC-15 Employee receives decision notification.  
AC-16 Employee receives completion notification.  
AC-17 Manager-only UI is hidden from Employee.  
AC-18 IT-only UI is hidden from Employee/Manager.  
AC-19 Version history is enabled on the SharePoint request list.  
AC-20 All manual test cases have recorded results before project is marked completed.
