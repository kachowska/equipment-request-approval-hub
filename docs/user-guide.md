# User guide

## Employee

1. Open the app.
2. Select **New request**.
3. Enter the device, department, reason and urgency.
4. Save the draft.
5. Submit for approval.
6. Track status in **My requests**.

## Manager

1. Open **Manager queue** to review pending requests.
2. Review request details.
3. Respond using the Microsoft Approval card in Outlook, Teams or the Approvals experience.
4. Add a comment when rejecting.

## IT

1. Open **IT queue**.
2. Pick an approved request.
3. Mark it `In Progress`.
4. Fulfill the request.
5. Mark it `Completed`.

Employees cannot see Manager/IT navigation actions in the app.
